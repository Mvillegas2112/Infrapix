Infrapix

Herramienta pública para explorar imágenes reales del cielo de SPHEREx y detectar objetos en movimiento a lo largo del tiempo.

Usar la herramienta Cómo funciona

Explorador SPHEREx

Conectado al backend real. Los datos se descargan directamente de NASA/IPAC IRSA.

Escribí el nombre o la designación de un objeto astronómico. Infrapix consultará diferentes catálogos para identificarlo y buscará observaciones reales de SPHEREx.

El Desafío

SPHEREx mapea el cielo cada seis meses en 102 bandas de luz infrarroja cercana.

🌌

Más de mil millones de objetos

Estrellas, asteroides, cometas, enanas marrones y galaxias. Muchos se mueven entre observaciones.

👁️

Comparación temporal

Objetos como Plutón se descubrieron al comparar imágenes tomadas en diferentes momentos.

👥

Ciencia ciudadana

Se necesita una herramienta pública para que cualquiera pueda explorar SPHEREx.

Cómo funciona

Ingresas un objeto

Escribís su nombre o ingresás RA / Dec.

Identificación astronómica

Se consultan catálogos para obtener sus coordenadas.

Backend consulta IRSA

Busca observaciones reales de SPHEREx y procesa archivos FITS.

Imágenes y Blink

Explorás imágenes reales o comparás observaciones con Blink.

Objetos recomendados

Barnard's Star

Gran movimiento propio. Ideal para probar detección de movimiento.

Epsilon Indi B

Par de enanas marrones cercanas.

WISE 0855

Enana marrón de movimiento rápido.

RW Aurigae & R Draconis

Estrellas variables (cambios de brillo).
